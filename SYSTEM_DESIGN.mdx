# SD-Client-Proposal System Design

## Overview

A **React-based client proposal builder** that enables agencies to create, edit, and export professional multi-page proposals as high-resolution PDFs. Built with TypeScript, React 19, Vite, and Tailwind CSS.

---

## Architecture

### Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | React 19, TypeScript, Vite 6 |
| **Styling** | Tailwind CSS 4, CSS Variables |
| **State** | React Hooks (useState, useEffect, useRef, useCallback) |
| **Persistence** | localStorage (client-side only) |
| **PDF Export** | html2canvas + jsPDF |
| **Icons** | Lucide React |
| **Animations** | Framer Motion |
| **AI Integration** | @google/genai (optional) |
| **Server** | Express + Vite dev middleware (SSR-ready) |

  id: string;

  milestonesData?: MilestonesPageData;

## Key Features

### 1. Multi-Mode View System

| Mode | Description |
|------|-------------|
| **Normal** | Sidebar editor (left) + full paginated preview (right) |
| **Split View** | Editor + single active page preview side-by-side |
| **Preview Only** | Full-width swipeable preview, no editor |

### 2. Page Types (7)

| Type | Use Case |
|------|----------|
| `cover` | Hero page with background image, client name, date |
| `category-table` | Two-column scope/deliverables tables |
| `pricing-highlight` | Prominent price box + notes + optional detail table |
| `deliverables-grid` | Card grid with icons, badges, descriptions |
| `milestones` | Timeline phases with duration & deliverables |
| `terms-signature` | Legal terms, payment terms, dual signature blocks |
| `freeform` | Custom narrative content (executive summary, etc.) |

### 3. PDF Export (`pdfGenerator.ts`)

- **High-resolution**: 3x scale (configurable)
- **Chunked rendering**: Processes pages in batches (2-3) to prevent OOM on mobile
- **Progress tracking**: Real-time callbacks with ETA
- **Abort support**: Cancellable via AbortController
- **Fallback**: Blob download if `pdf.save()` fails
- **Image handling**: CORS + timeout + preload
- **OKLCH fix**: Replaces unsupported CSS color functions for html2canvas

### 4. Sharing & Import

- **URL hash sharing**: Serializes full proposal to `#proposal=<encoded-json>`
- **Import modal**: Paste JSON or load from shared URL
- **localStorage persistence**: Auto-saves all proposals

### 5. Responsive Design

- **Desktop**: Persistent 380px sidebar
- **Mobile (<1024px)**: Slide-out drawer + FAB for actions
- **Touch**: Swipe navigation between pages (SwipeablePages)
- **Zoom**: 0.5x–1.5x canvas scaling

## Deployment Notes

- **Static hosting**: `dist/` contains client assets + `server.cjs` for SSR
- **Environment**: Requires `GEMINI_API_KEY` for AI features (optional)
- **No database**: All data in localStorage / URL hash
- **Node 18+** required for `fetch`, `AbortController`, modern globals

## Extensibility Points

1. **Add page type**: 
   - Add to `PageType` union in `types.ts`
   - Create component in `components/`
   - Add case in `ProposalPageCanvas.tsx`
   - Add button in `ProposalEditor.tsx` + `handleAddPage()` in `App.tsx`

2. **Add theme**: 
   - Add to `TemplateStyle` union
   - Define defaults in `ThemeSelector.tsx`

3. **Add export format**: Extend `pdfGenerator.ts` or add new lib

4. **Backend persistence**: Replace localStorage with API calls in `App.tsx` effects
