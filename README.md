# SD Client Proposal

A React-based client proposal builder for creating, editing, and exporting professional multi-page proposals as PDFs.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
